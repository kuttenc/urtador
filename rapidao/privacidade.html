LEILÃO RAPIDÃO

Política de privacidade

Atualizado em 23 de outubro de 2026.

1. Dados nesta página

Esta página estática não pede nome, documento, telefone, cartão ou senha. A confirmação dos termos é guardada apenas no navegador, para não abrir o aviso a cada visita.

2. Acesso ao Urtador

O acesso por código abre o Urtador, que possui política e fluxo de acesso próprios. Não digite senha ou código de acesso em sites de terceiros.

3. Links externos

Ao abrir uma plataforma externa, a coleta de dados passa a seguir a política dessa plataforma. O Leilão Rapidão não controla esse tratamento.

4. Contato

Para assuntos do Leilão Rapidão, use os canais públicos do Urtador. Para compras, lances ou créditos de plataformas externas, use o atendimento oficial delas.
